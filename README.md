# AE Turns Website

The public-facing AE Turns website is built with React, TypeScript and Vite.
It currently includes the home page, company overview, service descriptions,
company differentiators and contact details. The admin panel and backend are
planned as a later phase.

## Run locally

```sh
npm install
npm run dev
```

## Verify and build

```sh
npm run build
npm run preview
```
