# AE Turns Website

The public-facing AE Turns (Pvt) Ltd website is built with React, TypeScript,
React Router and Vite. Its public pages are Home, About Us, Solutions, Careers,
Contact Us, Privacy Policy and Terms & Conditions. The administration panel
and backend are planned as a later phase.

Company statistics remain marked for confirmation; customer names and logos
are not shown until approved. News, testimonials and team sections are omitted
until content is provided. Careers currently displays “No Current Vacancies.”

Contact enquiries are prepared in the visitor’s default email application.
The website does not send or store form submissions. CV uploads are not
available while there are no active vacancies. When a vacancy is published,
applicants will need to attach their CV to the prepared email themselves.

## Run locally

```sh
npm install
npm run dev
```

## Verify and build

```sh
npm run build
npm run preview
```
